## FINAL SELECTED: C1 — Persistence-Routed Learning (PES)
Scientific thesis: Memory hierarchy structure (context/state/moments/weights) should not be designed but
should emerge as the solution of a per-trace persistence-allocation problem under write/maintenance
tariffs and capacity constraints, optimized jointly with prediction.
Central falsifiable claim: A tiny learner equipped ONLY with the PES rule (no architecture-specific
memory designs) matches-or-beats matched fixed-profile mechanisms across stationary, drifting, and
interleaved regimes SIMULTANEOUSLY — something no single fixed profile can do — and exhibits signature
behaviors (bimodal persistence; post-error promotion transients) absent in all baselines.
